# LifePath 比赛演示脚本

## 1. 开场（20 秒）
今天演示的是 **LifePath**：一个基于个体建模的长期决策优化系统。它不是普通 AI 助手，而是一个能持续理解用户、并在关键节点提供深度分析与决策辅助的聊天型智能伙伴。

## 2. 先看主界面（20 秒）
- 左侧：多会话与不留痕聊天
- 中间：聊天主界面
- 顶部：LifePath 模式切换
- 右侧：四层记忆与配置

## 3. 先展示上传资料（30 秒）
上传一段自述/聊天记录。
强调：系统会把原始材料转成静态画像、动态记忆和当前状态快照。

## 4. 展示三种模式差异（90 秒）
统一问题：
“请你根据我的资料，帮我分析我现阶段是考研还是找工作更好？”

### 普通聊天
展示：先接住、轻追问，不急着下结论。

### 深度理解
展示：从“选项问题”拉到“你为什么会在这种节点卡住”。

### 深度理解 + 自我对立视角
展示：把内在反对声音外化出来。

### 决策辅助
展示：比较路径、收益、后悔风险。

### 决策辅助 + 多角色聊天
展示：当前的你 / 未来的你 / 理性导师 / 情绪支持者。

## 5. 展示不留痕聊天（20 秒）
切到不留痕聊天，强调：读取已有理解，但不写回长期记忆。

## 6. 展示四层记忆（30 秒）
点击右侧四层记忆浮层：
- 静态背景知识
- 动态记忆
- 当前会话短期记忆
- 当前状态快照

## 7. 收尾（20 秒）
总结：LifePath 不是做一次分析，而是把“长期理解 + 对话体验 + 决策能力”放进同一个系统里。
